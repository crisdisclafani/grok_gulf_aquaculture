# Gulf Aquaculture — Audiences website concept (demo)

Static multi-audience website concept by Kriswa International: Science, Technology & Sustainable Production.

**Live:** https://crisdisclafani.github.io/grok_gulf_aquaculture/

## How to use
- Open the page and browse by audience (operators, government, research) or by section.
- Content is driven by `js/content.js` (ready for a later CMS migration).
- Arabic / RTL is a placeholder for the CMS phase.

## Important
This is a **concept demo**, not an official site of any organisation. Many figures, contact details, and media slots are placeholders marked in the UI.
